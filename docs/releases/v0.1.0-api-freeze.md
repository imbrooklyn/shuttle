# v0.1.0 API freeze review

- Date: 2026-08-22
- Status: accepted for the first public pre-v1 release

This review covers every declaration in `api/shuttle-v1.txt` and the observable
contracts in `API_SPEC.md`. The final candidate SHA is recorded by the release
workflows and GitHub release rather than embedded here.

## Go 1.27 boundary

- `go.mod`, CI, release workflows, and documentation consistently require Go
  1.27 and validate with Go 1.27.0.
- Shuttle intentionally uses Go 1.27 generic methods for fluent operations that
  introduce result or key types. No package-level compatibility fallbacks are
  included.
- The Go 1.27 release notes confirm generic methods and broader function-type
  inference. They list no change to the `iter.Seq` protocol used by Stream.
- Go 1.27's `encoding/json` implementation change retains the v1 API behavior.
  Shuttle's JSON contract was revalidated with Go 1.27.0 rather than inferred
  from an earlier toolchain.

References:

- <https://go.dev/doc/go1.27>
- <https://go.dev/ref/spec>

## Function and method boundary

- Type-changing Optional and Stream operations and fluent projected comparator
  levels remain generic methods, which is the reason for the Go 1.27 minimum.
- Operations whose receiver element requires a new constraint or whose shape is
  naturally multi-input remain package functions, including `Distinct`,
  `Sorted`, `Min`, `Max`, `Chunk`, `Window`, `WindowStep`, `Enumerate`, and
  `Zip`.
- `Contains` remains package-level because its element type must be comparable.
- The generated public API and GoDoc snapshot exactly matches the committed
  baseline. No declaration was added, removed, or changed during this review.

## Optional JSON semantics

- None and a present nil pointer, slice, map, or interface both encode as JSON
  `null`; decoding `null` always produces None. The lossy presence-bit round
  trip is intentional and documented.
- `omitzero` omits None through `IsZero`; `omitempty` does not omit the
  non-pointer Optional struct value. Some containing a zero or nil value is not
  considered empty by Shuttle.
- A non-null decode starts from a fresh zero `T`; a decode error leaves the
  receiver unchanged. A nil `*Optional[T]` receiver returns an error.
- Custom marshal and unmarshal behavior, malformed input, whitespace around
  `null`, omission, and present-nil round trips have direct tests.

## Slice ownership

- `stream.Of` shallow-snapshots its variadic slice; `FromSlice` deliberately
  retains a zero-copy view. `FlatMapSlice` traverses callback-owned storage
  without copying it.
- `Collect` returns fresh result storage. `AppendTo` follows ordinary `append`
  semantics and may reuse caller-provided capacity.
- `Chunk` and `WindowStep` return independently owned slices with capacity equal
  to length. `GroupBy` returns a caller-owned group slice and non-aliasing value
  slices. Element values remain shallow copies.
- Variadic comparator, predicate, and Stream composition snapshots descriptor
  slices while preserving ordinary shallow aliases captured by callbacks.
- Mutation and retention tests cover every ownership distinction above.

## Verification evidence

- `go test -count=1 -cover ./...`, `go test -count=1 -race ./...`, and
  `go vet ./...` pass with Go 1.27.0.
- Optional tests pass with both Go 1.27's default JSON implementation and
  `GOEXPERIMENT=nojsonv2`.
- Staticcheck 2026.2 passes. Govulncheck v1.7.0, rebuilt with Go 1.27.0,
  reports no vulnerabilities using the database updated at
  2026-08-21 20:38 UTC.
- The generated API/GoDoc snapshot exactly matches `api/shuttle-v1.txt`.
- Actionlint validates every workflow, and the release-fuzz target manifest
  exactly matches all 12 committed fuzz functions.
- Every fuzz target passes a local invocation smoke test. The separately
  retained GitHub release workflow supplies the required minute-scale run.

## Decision

No release-blocking API or semantic correction was found. The reviewed surface
is accepted for `v0.1.0`; it remains explicitly unstable until `v1.0.0`, so any
future breaking pre-v1 change must be called out in the changelog.
